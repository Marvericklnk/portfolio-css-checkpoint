# Portfolio CSS Checkpoint

A styled version of Marvin’s HTML portfolio, built with plain HTML, CSS, and a small JavaScript form demo.

## Run locally

Download and extract this repository, then open `index.html` in a browser. You can also open the folder in VS Code and use Live Server. No npm commands are needed.

## Checkpoint requirements

- `styles.css` is linked in the HTML head.
- Navbar list items use `display: inline-block` to sit beside one another.
- Roboto is loaded through Google Fonts and applied throughout the page, with Arial and sans-serif fallbacks when offline.
- HTML classes include `navbar`, `nav-list`, `hero`, `project-card`, and `skills`.
- Custom colours, responsive project cards, hover effects, keyboard focus styles, and a mobile layout complete the design.

The previous portfolio sections and welcome audio are retained. The contact form validates inputs but does not send messages.

## Files

- `index.html`: semantic page structure and content
- `styles.css`: all visual styling
- `script.js`: demo contact confirmation
- `assets/welcome.wav`: original welcome chime
